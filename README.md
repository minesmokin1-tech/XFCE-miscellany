This project was created with the help of AI, with the goal of providing an easy, fast, and optimized way for you to have widgets on your XFCE desktop. 


- Python 3
- PyGObject 3.50.0 whit GTK 3.24, GDK 3, Pango, PangoCairo y GLib.
- pycairo 1.27.0 
- psutil 7.0.0

Install dependences

Debia/Ubuntu:

sudo apt update && sudo apt install -y python3-psutil python3-gi python3-gi-cairo python3-cairo

Arch:

sudo pacman -Syu --needed python-psutil python-gobject python-cairo





this program is only for XFCE
